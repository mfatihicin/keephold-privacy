# keephold-privacy

KeepHold (iOS / Android private vault app) public pages, served with GitHub Pages:

- `index.html` — Privacy Policy (EN + TR)
- `termsofuse.html` — Terms of Use (EN + TR)
- `support.html` — Help Center (links to FAQ and e-mail)
- `faq.html` — Frequently Asked Questions (EN + TR)
- `kvkk.html` — KVKK Aydınlatma Metni (TR) + Privacy Notice under Turkish Law No. 6698 (EN)

The app itself is not in this repository.
